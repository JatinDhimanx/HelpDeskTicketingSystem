How to Run on Windows 11

  1. Download HelpDeskTicketingSystem.jar using the button above.
  2. Open Command Prompt or PowerShell in your download folder.
  3. Execute the JAR file:
java -jar HelpDeskTicketingSystem.jar

Tip: You can also simply double-click the .jar file if Java file associations are configured.

Key Features

  • FlatLaf SaaS UI: Clean modern light theme with custom status & priority pill badges.
  • Cloud MySQL Backend: Persistent remote storage on Filess.io.
  • Connection Pooling: Sub-second response times without handshake freezes.
  • Escalation Daemon: Background daemon automatically escalates tickets exceeding SLA thresholds.
  • Role Dashboards: Dedicated views for Admin, Agent, and User.
